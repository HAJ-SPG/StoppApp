# Nur die App öffnet die Datenbank, Widget und Live Activity lesen einen Schnappschuss

Die SQLite-Datenbank öffnet ausschließlich die App. Widget, Live Activity und Notification lesen nur einen kleinen Widget-Schnappschuss (laufende Messung mit Startzeit, nächstes Ereignis), den die App nach jeder Änderung in den App-Group-Speicher bzw. die SharedPreferences schreibt. Ein Tippen auf deren Buttons weckt die App im Hintergrund (`home_widget`-Callback bzw. `LiveActivityIntent`), und die App schreibt die Messung. Klappt das nicht, landet die Aktion mit Zeitstempel in einer Warteschlange, die die App beim nächsten Start abarbeitet. Grund: Eine SQLite-Datei, die App und Extension gemeinsam offen halten, führt auf iOS zu `0xdead10cc`-Abbrüchen. Wer die Datenbank direkt im Widget öffnen will, sollte das wissen.
